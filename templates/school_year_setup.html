What happens when you save?

The system will:

  • Make this the active school year.
  • Set each entered amount as the employee's official beginning balance.
  • Set the employee's current balance to the same amount.
  • Create or update a permanent Beginning Balance entry in the leave ledger.

Only employees with an amount entered will be updated.
